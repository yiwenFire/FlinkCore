
优化假设与A/B实验设计

    假设1：关卡难度过高
        优化方案：降低BOSS血量10%，增加1个中途存档点。
        实验设计：
            分组：随机抽取10%玩家进入实验组（新版本），其余为对照组。
            指标：通过率、平均尝试次数、失败后次日留存率。
            统计方法：T检验对比差异，置信度95%。

    假设2：玩家引导不足
        优化方案：在关卡开始时增加动态教学提示（如“使用技能打断BOSS大招”）。
        实验设计：
            分组：新玩家定向分桶（50%实验组 vs 50%对照组）。
            指标：首次尝试成功率、教学提示点击率、关卡耗时分布。
